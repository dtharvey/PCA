How PCA Changes the Data Cloud

The emphasis of this learning module is visualizing the process by which a large data set with many measurement dimensions (the original axes) is reduced to a much smaller data set that has fewer dimensions. We used a data set with 205 samples arrayed in three dimensions—which we described as a data cloud—and located PC1, PC2, and PC3 by rotating the data cloud until we identified three mutually perpendicular axes that seemed to account for most of the variability in the samples. Although we described the process as a reduction in dimensionality in which we reduced the data set’s shape from a three-dimensional ellipsoid, to a two-dimensional ellipse, and to a one-dimensional line, we did not show that this is indeed what happens. The figure on the upper right illustrates how this works. The data cloud begins as an ellipsoid in three dimensions and the first principal component axis. The figure on the lower right shows that the data cloud becomes a two-dimensional ellipse when the data cloud is projected onto the two-dimensional plane that is perpendicular to PC1. This is the meaning of reducing dimensionality.

Is This Really How a Principal Component Analysis is Accomplished?

No. Although a PCA analysis involves rotating the axes and finding scores—and loadings (see below)—a PCA analysis accomplishes this through the application of a quantitative algorithm that relies on matrix algebra. The details of this are beyond the scope of this learning module. For an introduction to PCA, see the R package LearnPCA, which provides a series of vignettes that explain PCA starting from basic concepts. Loadings (there is more to PCA than scores)

Each sample’s set of scores show the sample’s location on each of the principal component axes. Scores are important because they help determine the number of principal component axes to keep (see LearnPCA). To fully model the original data, we also have to know the location of the principal component axes relative to the original axes. These are given by the angles between the axes; the cosines of these angles are called the loadings). Although not considered in this learning module, loadings are obtained from the same mathematical algorithm that gives the scores; see LearnPCA for more information on loadings.
